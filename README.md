# SMARTLITE

SMARTLITE is a desktop GUI application for classifying electronic component images with an MLP model.

The project currently supports 20 classes:

- battery holder
- breadboard
- capacitor
- connector
- crystal oscillator
- diode
- fuse
- heat sink
- ic chip
- inductor coil
- jumper wire
- led
- microcontroller board
- potentiometer
- power supply module
- relay
- resistor
- switch
- transformer
- transistor

## Project Structure

```text
MLP_Project/
|-- app.py                  # SMARTLITE GUI
|-- app.py.py               # Compatibility launcher
|-- requirements.txt        # Python dependencies
|-- Requirements.text       # Same dependency list for compatibility
|-- dataset/                # Raw electronic component images
|-- notebooks/
|   |-- data.npz            # Prepared train/validation arrays
|   |-- EDA.ipynb           # Data preparation notebook
|   `-- MLP_Training.py     # Keras/TensorFlow MLP training script
`-- models/
    |-- mlp_model.keras      # Generated by notebooks/MLP_Training.py
    |-- mlp_model.joblib     # Generated if TensorFlow is unavailable
    `-- mlp_model_metadata.npz
```

## Setup

Create and activate a virtual environment:

```bash
python -m venv .venv
.venv\Scripts\activate
```

Install requirements:

```bash
pip install -r requirements.txt
```

## Train The Model

The recommended training script is the Keras MLP script:

```bash
python notebooks\MLP_Training.py
```

It loads `notebooks/data.npz`, trains the MLP model, then saves:

```text
models/mlp_model.keras
models/mlp_model_metadata.npz
```

If TensorFlow is not available on your Python version, the same script automatically trains an MLP fallback and saves:

```text
models/mlp_model.joblib
models/mlp_model_metadata.npz
```

## Run The GUI

```bash
python app.py
```

Then:

1. Click `Browse Image`.
2. Select a component image.
3. Click `Classify`.
4. SMARTLITE shows the predicted class and top confidence scores.

## Image Preprocessing

The app uses the same preprocessing style as the prepared dataset:

- converts the image to grayscale
- resizes it to `64x64`
- scales pixels to the `0..1` range
- flattens the image to 4096 features for the MLP

## Notes

- The old `models/mlp_model.keras.py` file is empty, so the fixed Keras training script saves to `models/mlp_model.keras` instead.
- Tkinter is included with most Python installations and does not need to be listed in `requirements.txt`.
- The GUI loads the model generated by `notebooks/MLP_Training.py`.
- The current saved MLP model is functional, but its validation accuracy is modest. Better accuracy will likely need a CNN or feature extraction model.
